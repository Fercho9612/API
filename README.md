# 🎬 API y Catálogo de Películas (Monorepo)

Proyecto full-stack desarrollado con Node.js, Express, MongoDB y React (Vite).

## 📋 Requisitos previos
* Tener instalado **Node.js** (versión 18 o superior).
* Archivo `.env` configurado dentro de la carpeta `backend/` con la cadena de conexión a MongoDB (`MONGO_URI`) y el puerto (`PORT=3000`).

## 🚀 Instalación y Ejecución

1. **Instalar todas las dependencias** (raíz, backend y frontend) ejecutando en la carpeta principal:

   npm run install:all

2. **Iniciar el proyecto completo** (Backend y Frontend al mismo tiempo) desde la raíz del proyecto:

   npm run dev

3. **Abrir en el navegador:**
    * **Frontend (Interfaz):** `http://localhost:5173`
   
    Opcional: identificar que este corriendo
   * **Backend (API):** `http://localhost:3000`
